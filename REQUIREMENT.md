# Toy Robot

## Functional Requirements

- The application is a simulation of a toy robot moving on a square tabletop, of dimensions 5 units x 5 units.
- There are no other obstructions on the table surface.
- The robot is free to roam around the surface of the table, but must be prevented from falling to destruction. Any movement that would result in the robot falling from the table must be prevented, however further valid movement commands must still be allowed.

## Non Functional Requirements

- It should be a UI application that can be run on a web browser.
- The application does not need to consider the responsive design, but it should be visually appealing and user-friendly.
- The application should be developed by using ReactJS and TypeScript.
- The application should be well-structured and maintainable.
- The UI should contains a grid board table view that represents the 5x5 tabletop.
- The movement should be controlled by buttons on the UI, and the current position and direction of the robot should be displayed on the UI as well.
- It should use lucide icon for the representation of the robot on the grid board.
